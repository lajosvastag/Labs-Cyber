# 01 — Phishing awareness

Este lab é uma página estática de conscientização. Ela **não possui campo de senha, não envia dados e não imita uma marca real**. O objetivo é treinar a leitura de sinais: domínio, urgência artificial, pedido de segredo e links suspeitos.

Abra `index.html` no navegador. Exercício: liste pelo menos cinco indícios e escreva uma ação segura para cada um.
