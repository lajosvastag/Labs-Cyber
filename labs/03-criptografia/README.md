# 03 — Criptografia

O script apresenta uma cifra de César e XOR apenas para visualizar conceitos de chave, transformação e reversibilidade. São **algoritmos didáticos e inseguros**: não use para proteger dados reais.

```bash
python3 crypto_lab.py --demo
python3 crypto_lab.py --caesar "mensagem" --shift 3
```

Exercício: explique por que uma chave pequena pode ser testada por força bruta e quais propriedades um esquema moderno precisa oferecer.
