# Como contribuir

1. Crie uma branch com uma mudança pequena e explicável.
2. Mantenha os exercícios locais, fictícios e não destrutivos.
3. Não adicione credenciais, tokens, malware, payloads reais ou alvos externos.
4. Inclua testes para qualquer mudança de lógica.
5. Descreva no pull request o objetivo, o risco didático e como validar.

Antes de abrir o pull request:

```bash
python3 -m unittest discover -s tests -v
```
