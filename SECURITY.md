# Segurança e escopo

Este repositório é um laboratório educacional. Relatos devem considerar apenas bugs no código do lab e não testes contra infraestrutura externa.

- Não há coleta, armazenamento ou envio de credenciais reais.
- Os servidores escutam somente em `127.0.0.1`.
- Não execute scanners, payloads ou testes de intrusão fora de um ambiente autorizado.
- Para relatar um problema, abra uma issue descrevendo a reprodução mínima sem incluir dados sensíveis.
